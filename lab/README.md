# lab — 아직 앱에 안 들어간 것들

여기 있는 것은 **`index.html` 과 아무 상관이 없다.** 앱은 한 글자도 안 바뀐다.
구상한 기능을 따로 만들어 두었다가, 좋으면 그때 합친다.

| 폴더 | 무엇 | 합치는 법 |
|---|---|---|
| `vf-bg/` | 말씀 전체화면 **'내 배경'** — 내 사진으로 배경 만들기 + 템플릿 | `vf-bg/INTEGRATION.md` |

## 실험실을 어떻게 보나

`lab/vf-bg-lab.html` 은 혼자 도는 한 파일이다. 병합되어 배포되면
**https://block7.my/lab/vf-bg-lab.html** 로 아이폰에서도 열린다.
사진을 올려 실제로 만들어 볼 수 있고, 만든 것은 그 브라우저에만 담긴다
(앱 데이터·클라우드와 이어져 있지 않다).

- 실험실 파일은 `./lab/vf-bg/build-lab.sh` 가 만든다 — **손으로 고치지 말 것**
- 테스트: `node lab/vf-bg/test_vfbg.js`
- ⚠️ `tools/check.sh` 는 이 폴더를 검사하지 않는다 (앱이 아니므로)
