# 명제집 — 구글 시트로 등록하기

**명제집은 따로 있는 것이 아니라 「말씀 모음」 중 하나다.** 그래서 별도 탭이 없다.
새 말씀 모음을 하나 만들고 거기에 명제 시트를 붙이면, 앱이 머리글을 보고
**스스로 명제 시트임을 알아본다.**

그 뒤로는 말씀 모음이 하는 일을 전부 그대로 한다 —
켜고 끄기 · 6자리 코드로 발행 · 구독 받기 · 매일 자동 갱신.

---

## 1. 시트 머리글 (첫 줄)

**`명제 ID` 와 `명제` 두 열이 반드시 있어야 한다.** 이 둘로 명제 시트임을 알아본다.
하나라도 없으면 평범한 말씀 시트로 읽혀 **명제가 뭉개진다.**

| 열 이름 | 필수 | 앱에서 쓰이는 곳 |
|---|---|---|
| `명제 ID` | **필수** | 명제를 구별하는 유일한 열. `P0001` 처럼 **P + 숫자** |
| `명제` | **필수** | 전체화면 **본문** (좌정렬로 흐른다) |
| `대표 문구` | | 전체화면 **위쪽 타이틀** (좌·중앙·우 무작위, 손으로 그은 획) |
| `카테고리` | | **대분류** 자리 (필터 칩 '예배') |
| `설교 제목` | | **소주제** 자리 (필터 칩 '제목') |
| `주제 태그` | | 태그. 쉼표(`,`) 나 세미콜론(`;`) 으로 여러 개 |
| `설교 본문` | | **장절 줄**. 최대 **세 개**까지. 비워도 된다 |
| `인용 본문` | | 설교에서 인용된 모든 본문. **앱은 읽지 않는다** (너무 많다) |
| `성경권` | | 성경별 필터. 비워 두면 `설교 본문` 에서 앱이 뽑는다 |
| `날짜` | | 정렬·'최근 설교' 타일에 쓰인다 |
| `데이터 상태` | | 있으면 **`활성` 인 줄만** 들어온다. 나머지는 조용히 건너뛴다 |

열 **순서는 상관없다.** 이름으로 찾는다.

### ⚠️ 명제 ID 가 왜 필수인가

한 설교에서 명제가 여러 개 나온다. 장절·설교 제목·핵심 주제가 **셋 다 같은**
명제가 흔하다 (실제 시트에서 275개 중 상당수). 명제 ID 가 없으면 앱이 그것들을
**같은 것으로 보고 서로 덮어써서**, 275개가 87자리로 뭉친다.

`P0001` 형식이 아닌 줄은 데이터가 아닌 것으로 보고 건너뛴다 (머리글·메모 줄 등).

## 2. 등록하는 순서

1. 말씀설정을 연다 → **말씀 모음** 탭
2. 모음 목록의 **`+`** → **새로 만들기** → 이름을 짓는다 (예: `TLC 명제집`)
   - ⚠️ 암송 말씀과 **같은 모음에 섞지 말 것.** 따로 두어야 따로 켜고 끄고,
     따로 발행·구독할 수 있다.
3. 그 모음을 열어 **구글 시트** → 링크를 붙인다
   - 시트는 **'링크가 있는 모든 사용자 — 뷰어'** 로 공유돼 있어야 읽힌다
4. 받아오면 모음 이름 옆에 작은 **`명제`** 표시가 붙는다 — 명제로 읽혔다는 뜻이다

표시가 안 붙으면 머리글(`명제 ID`·`명제`)을 다시 본다.

---

## 3. 다른 사람에게 주기

- **6자리 코드** — 모음을 길게 눌러 공유. 받는 사람은 `+` → 구독 받기.
  구독한 모음은 **수정·삭제가 막혀 있고** 해지만 된다. 매일 하루 시작 시간에
  최신 내용으로 따라온다.
- 교회 단위(`sweeter.my/tlc` 같은 이름 주소)는 아직 만들지 않았다.
  만들 때도 **이 구독 장치 위에 얹는다** — 6자리 코드 공유는 그대로 둔다.

⚠️ v26-0831-2 이전에 발행·구독된 명제집은 명제 ID 가 실려 가지 않아
**구독자 쪽에서 명제가 뭉개져 있다.** 발행자가 다시 갱신하면 제대로 들어오고,
뭉개져 있던 옛 항목은 지워지지 않고 남는다(잃는 것은 없다) — 모음 편집창에서
손으로 지우면 된다.

## 4. 전체화면에서 어떻게 보이나 (v26-0831-3)

명제는 암송 말씀과 **같은 화면**을 쓰되 세 가지가 다르다:

| | 암송 말씀 | 명제 |
|---|---|---|
| 본문 | 가운데 정렬, 의미 단위 줄바꿈 | **좌정렬**, 자연스럽게 흐름 |
| 위쪽 | (없음) | **대표 문구 타이틀** — 좌·중앙·우 무작위 + 손으로 그은 획 |
| 강조 칠하기 | 시트 '강조 문구' 를 본문에 칠함 | **안 칠한다** (대표 문구는 제목이라 본문에 없다) |

대분류·소주제·태그·반응 아이콘은 **암송 말씀과 똑같다** (자리·서식·기능).

### 장절 줄 — 설교 본문 세 개 (v26-0831-12)

`설교 본문` 에 본문이 여럿이면 **셋을 다 쓰고, 하나하나가 제 단추**가 된다.
누르면 **그 성경으로 거른 타일뷰**가 열린다 — 셋이 각각 다른 필터다.

    마태복음 5:13 · 로마서 8:28 · 에베소서 2:8-9
      ↑누르면 마태복음   ↑로마서      ↑에베소서

- 넷 이상 적혀 있으면 **앞의 세 개만** 쓴다
- 참조 안의 쉼표는 자르지 않는다 (`요한복음 1:1,14` 는 하나다).
  쉼표 뒤가 **한글로 시작할 때만** 다음 참조로 본다
- `성경권` 열을 비워 두어도 여기서 세 권이 뽑혀 **성경별 필터에 다 걸린다**
- 본문이 하나뿐이면 예전 그대로 줄 전체가 하나의 단추다
