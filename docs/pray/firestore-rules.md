# 기도노트 — 로그인 서버 설정 (HB, 한 번만)

BLOCK7 · Sweeter · 용돈 친구들의 규칙은 건드리지 않아요 — **한 덩어리를 덧붙이기만** 해요.
에뮬레이터(서버 흉내 장치)로 시험했어요: 내 칸은 읽히고, 다른 계정 · 로그인 안 한 사람은 못 읽어요
(`tests/e2e/pray_sync.js` ⑪).

이걸 붙이기 전에는 로그인은 되지만 설정 › 계정에 **"서버 권한이 아직 없습니다"** 가 떠요. 자료는 이 기기에 그대로 있어요.

## 보안 규칙 붙여 넣기

1. https://console.firebase.google.com → **block7-8f24e** → 왼쪽 **빌드** → **Firestore Database** → 위쪽 **규칙** 탭
2. 맨 위 `match /databases/{database}/documents {` 줄을 찾아요. 그 **바로 다음 줄**에 아래 덩어리를 붙여 넣어요.
   (용돈 친구들 덩어리 `// ── 용돈 친구들(wallet) …` 바로 위에 넣으면 돼요)
3. 오른쪽 위 **게시**. 빨간 오류가 나오면 게시하지 말고 캡처해서 보여 주세요.

```
    // ── 기도노트(pray) — 여기서부터 ──
    match /pray/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      match /c/{part} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
    // ── 기도노트 — 여기까지 ──
```

로그인 방법(이메일/비밀번호)은 BLOCK7 이 이미 쓰고 있어서 따로 켤 것이 없어요.

## 확인

1. 아이폰 기도노트 → 설정 › 계정 › **로그인** → Sweeter 와 같은 이메일 · 비밀번호
2. 설정 › 계정에 **"맞춤 · 방금"** 이 뜨면 올라간 거예요.
3. 아이패드 기도노트에서도 같은 계정으로 로그인 → 아이폰 자료가 그대로 와요.
   - 아이패드에도 이미 자료가 있으면 **"둘 다 자료가 있습니다"** 를 한 번 물어요. 지금 쓰는 쪽을 고르면 돼요
     (다른 쪽은 그 기기에 한 벌 남아요 — 설정 › 계정 › '맞추기 전에 남겨 둔 자료').
4. 아이폰에서 표시 색을 하나 칠해 보세요. 아이패드에 몇 초 안에 따라와요(앱을 다시 열지 않아도).

## 클라우드 모양 (참고)

- `pray/{uid}` — 머리: `wid`(쓰기 번호) · `n`(덩어리 수) · `people` · `groups` · `v`(앱 버전) · `at`
- `pray/{uid}/c/0`, `c/1` … — 자료 글을 25만 자씩 나눈 덩어리. 머리와 같은 `wid` 를 갖는다.
- `users/{uid}`(BLOCK7 · Sweeter 상태 문서)는 건드리지 않는다. uid 가 같으니 P-7 에서 Sweeter 가 이 칸의 기도 시간을 읽으면 된다.
