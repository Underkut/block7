# 기도노트 시리로 기도 넣기 — 설정 (HB, 한 번만) · 기도노트 v. 26-1030-1

두 가지 단축어를 만듭니다. 아이폰에서 만들면 **아이패드에도 저절로 생겨요** (iCloud).

| 단축어 | 이렇게 써요 |
|---|---|
| **기도 추가** (한 번에 말하기) | "시리야, 기도 추가" → "무엇을 넣을까요?" → **"청년부에 1셀에 김○○ 회복이라고"** → "청년부의 1셀에 넣었어요" |
| **기도 고르기** (골라서 넣기) | "시리야, 기도 고르기" → 그룹 목록이 뜸 → 고르기 → 서브그룹 목록 → 고르기 → 말하기 |

> 시리는 "…추가해줘" 까지 한 번에 받지 못해요. 그래서 **늘 두 박자**예요 — 단축어 이름을 부르고, 시리가 물으면 내용을 말해요.

## 1. 서버 올리기 (구글 Cloud Shell)

BLOCK7 '시리로 할일 넣기' 와 **같은 서버**(`b7siri`)라, 그때와 같은 명령이에요.

1. https://console.cloud.google.com → 위쪽 프로젝트가 **block7-8f24e** 인지 확인
2. 오른쪽 위 **>_ (Cloud Shell 활성화)**
3. 아래를 한 줄씩 붙여 넣고 엔터:

```
cd block7 && git pull && cd wallet-functions/src && npm install && cd ..
firebase deploy --only functions:wallet
```

- 성공 표시: `b7siri(asia-northeast3)` 가 **Successful update operation**
- ⚠️ 배포 중에 **삭제(deletion)를 묻는 화면이 나오면 반드시 N**
- 이걸 올려도 BLOCK7 '시리로 할일 넣기' 주소는 그대로 돼요 (주소가 앱마다 따로예요).

## 2. 주소 만들기 (아이폰 홈 화면 기도노트)

1. 기도노트를 열어요 (새 버전 **v. 26-1030-1** 이 저절로 들어와요 — 설정 맨 아래 글씨에서 확인)
2. 오른쪽 위 톱니 → **계정·자료** 탭 → '계정' 바로 아래 **시리로 기도 넣기**
3. **주소 만들기** → "시리 주소를 만들었어요"
4. **주소 복사**

- 로그인해야 보여요.
- "만들지 못했어요" 가 나오면 1번(서버 올리기)이 아직이거나 인터넷이 끊긴 거예요.

## 3-1. 단축어 '기도 추가' (한 번에 말하기 · 못 알아들으면 한 번 더 물어요)

아이폰 **단축어** 앱 → 오른쪽 위 **+** → 아래 동작을 차례로 더해요 (검색 칸에 굵은 글씨를 쳐서 찾아요).

1. **입력 요청** → 질문 칸: `무엇을 넣을까요?`
2. **변수 설정** → 변수 이름: `첫말` · 값: **제공된 입력**
3. **URL 콘텐츠 가져오기** → 파란 'URL' 칸을 눌러 **붙여넣기** (2번에서 복사한 주소)
   - 그 동작의 **›** (더 보기)를 눌러 펼치기 → 방법: **POST** · 본문 요청: **JSON**
   - **새로운 필드 추가 → 텍스트** → 키 `text` · 값은 위 변수 줄에서 **첫말**
   - **새로운 필드 추가 → 텍스트** → 키 `try` · 값 `1`
4. **변수 설정** → 변수 이름: `대답` · 값: **URL의 콘텐츠**
5. **만약** → 입력: **대답** · 조건: **다음을 포함함** · 글: `다시 말해`
6. (만약 **안쪽**에) **입력 요청** → 질문 칸을 누르고 변수 **대답** (시리가 "그룹 이름을 다시 말해 주세요" 를 읽어 줘요)
7. (만약 안쪽에) **URL 콘텐츠 가져오기** → 3번과 **같은 주소** · POST · JSON
   - 키 `text` · 값 **제공된 입력** (6번에서 말한 것)
   - 키 `prev` · 값 **첫말**
8. (만약 안쪽에) **변수 설정** → `대답` · 값: **URL의 콘텐츠**
9. (만약 종료 **아래**에) **결과 보기** → **대답**
10. 맨 위 이름을 `기도 추가` 로 → **완료**

- '그렇지 않으면' 칸은 비워 둬요 (지워도 돼요).
- 두 번째에는 **그룹 이름만** 말해도 돼요. 처음 말한 내용은 서버가 기억해서 이어 넣어요.
- 두 번째도 못 알아들으면 지도 맨 위 **'시리로 받은 기도'** 그룹에 넣고 시리가 그렇다고 말해요. 나중에 옮기면 돼요.

## 3-2. 단축어 '기도 고르기' (목록에서 골라서)

1. **URL 콘텐츠 가져오기** → 같은 주소 · POST · JSON · 키 `list` · 값 `1`
2. **텍스트 분할** → 기준: **새로운 줄**
3. **목록에서 선택** → 프롬프트: `어느 그룹이요?`
4. **변수 설정** → `그룹` · 값: **선택한 항목**
5. **URL 콘텐츠 가져오기** → 같은 주소 · POST · JSON · 키 `list` 값 `1` · 키 `g` 값 **그룹**
6. **텍스트 분할** → **새로운 줄**
7. **목록에서 선택** → 프롬프트: `어디에 넣을까요?`
8. **변수 설정** → `자리` · 값: **선택한 항목**
9. **입력 요청** → 질문: `무엇을 넣을까요?`
10. **URL 콘텐츠 가져오기** → 같은 주소 · POST · JSON
    - 키 `g` 값 **그룹** · 키 `s` 값 **자리** · 키 `text` 값 **제공된 입력**
11. **결과 보기** → **URL의 콘텐츠**
12. 이름을 `기도 고르기` 로 → **완료**

- 두 번째 목록: 맨 위 **여기에 바로 넣기**(그 그룹에) · 서브그룹들 · 맨 아래 **새 서브그룹 만들기**
- 첫 목록 맨 아래 **새 그룹 만들기** 를 고르면 다음 목록은 하나뿐이에요 → 고르고 새 그룹 이름을 말해요.
- 새 서브그룹 · 새 그룹을 고른 때는 9번에서 **이름**을 말하면 돼요.
- 시리로 부르면 목록이 화면에 떠요. **말로 골라도, 눌러 골라도** 돼요.
- 홈 화면에 올리기: 단축어를 길게 눌러 **공유 → 홈 화면에 추가**.

## 4. 말하는 법 ('기도 추가')

| 말 | 들어가는 곳 |
|---|---|
| 청년부에 1셀에 김○○ 회복이라고 | 청년부 › 1셀 맨 위 · '김○○ 회복' |
| 청년부에 수련회 장소라고 | 청년부 맨 위 |
| 청년부에 새가족이라고 서브그룹 추가해 줘 | 청년부 아래 새 서브그룹 '새가족' (서브그룹들 맨 위) |
| 중보팀이라고 그룹 추가해 줘 | 지도 맨 위에 새 그룹 '중보팀' |
| 1셀에 김○○ 회복 | 서브그룹 이름이 하나뿐이면 그룹 없이도 |

- 끝에 '…라고 기도 추가해 줘 · 넣어 줘 · 추가' 를 붙여도, 빼도 돼요.
- 띄어쓰기는 상관없어요 ('스데반 인턴십' = '스데반인턴십'). 한 글자쯤 잘못 들은 이름도 알아들어요.
- 같은 서브그룹 이름이 여러 그룹에 있으면("1셀") 그룹부터 말해 달라고 다시 물어요.
- 말한 것이 **이미 있는 사람 카드 이름과 똑같으면 그 사람 카드**에 이어요. 아니면 기도 항목으로 들어가요.
- 기도노트가 열려 있으면 곧바로, 아니면 다음에 열 때 들어가요 ("시리에서 N개 들어왔습니다").

## 문제가 생기면

- 시리가 "주소가 맞지 않아요" → 다른 기기에서 **주소 새로 만들기**를 눌렀거나 주소가 잘렸어요. 2번부터 다시 (단축어의 URL 칸 **다섯 곳 모두** 바꿔요 — '기도 추가' 둘 · '기도 고르기' 셋).
- 시리가 "기도노트가 아직 그룹 목록을 보내지 않았어요" → 기도노트를 한 번 열어 주세요 (로그인한 상태로). 그 말은 '시리로 받은 기도' 에 들어가 있어요.
- 시리가 "쪽지가 너무 많이 쌓였어요" → 기도노트를 한 번 열면 다 넣고 비워요 (50개까지 기다려요).
- 그룹 이름을 바꿨으면 기도노트를 한 번 열어 맞추기가 끝나야 시리가 새 이름을 알아요.
- 주소는 열쇠예요. 남에게 보내지 마세요. 새어 나갔으면 **주소 새로 만들기** — 옛 주소는 그 자리에서 멈춰요.

## 어떻게 도는가 (클로드용)

- 길: 단축어 → 서버 `b7siri` 의 `/pray`(`wallet-functions/src/praysiri.js`, 규칙 `praysiri-core.js`) → 우체통 `pray/{uid}/c/inbox` → 앱 `takeInbox` → `inboxApply`
- 서버가 이름을 아는 길은 앱이 맞추기 끝마다 쓰는 **그룹 차림표** `pray/{uid}/c/siridir` = `{v:1, g:[{i,n,p,a}]}` (`siriDir`) 하나. 사람 · 항목 이름은 없다.
- 서버는 기도노트 자료 덩어리(`pray/{uid}` · `c/0…`)를 읽지도 쓰지도 않는다.
- 열쇠: `b7siri/{sha256}` = `{uid, app:'pray', at}`. BLOCK7 열쇠는 `app` 없음. 서로의 주소로는 못 보낸다.
- 쪽지: `{id, from:'siri', say, at, gid, text, kind?:'sub'|'group', hold?:1}`
- 단축어 '만약' 은 대답에 `다시 말해` 가 있는지로 갈린다 — **다시 묻는 대답에만 그 말을 쓴다** (`tests/test_praysiri.js` ③ 이 지킨다).
- 시험: `tests/test_praysiri.js`(서버 + 앱 받기까지) · `tests/test_pray.js` ㉘(앱 받기 · 차림표) · 끝까지 `tests/e2e/pray_siri.js`(에뮬레이터 · 기기 셋)
