# 교역자 로테이션 — 예배팀 일정 받기 설정 (HB, 한 번만)

예배팀 로테이션(누가 어느 분당 예배에 어떤 파트로 서는지)을 서버가 **2시간마다** 받아 와서,
부산에 내려가는 날 분당 예배팀에도 들어가 있으면 **빨강**(예배팀 쪽이 아직 미정이면 노랑)으로 알려 줍니다 (R13).

- **읽기만** 합니다. 예배팀 시스템에는 아무것도 쓰지 않습니다.
- 열쇠는 **Secret Manager 의 `SCHEDULE_API_KEY`** 에만 있습니다(HB 가 넣음). 코드 · 저장소 · 화면 · 로그 어디에도 값이 없습니다.
- 받은 것 중 저장하는 사람은 **인도자 전원 + 우리 명단(사람 탭)에 있는 분**뿐입니다. 나머지 팀원 이름은 받자마자 버립니다.
- 사람 맞추기: 사람 탭의 이름 · 다른 이름으로 처음 한 번 맞추고, 그 뒤로는 예배팀 고유 id 로 맞춥니다.
  같은 이름이 둘이면 맞추지 않고 계정 메뉴에 '같은 이름이 둘이라 못 맞춘 분' 으로 보여 줍니다.
- 하루 12번만 부릅니다(예배팀 한도 100번).

## 0. 열쇠 넣기 — ✅ 했음 (11/16)

Cloud Shell 에서 `firebase functions:secrets:set SCHEDULE_API_KEY --project block7-8f24e`. 다시 할 필요 없습니다.
열쇠가 바뀌면 같은 명령으로 새 값을 넣고 1번(서버 올리기)을 다시 합니다.

## 1. 서버 올리기 (구글 Cloud Shell)

1. https://console.cloud.google.com → 위쪽 프로젝트가 **block7-8f24e** 인지 확인 → 오른쪽 위 **>_ (Cloud Shell 활성화)**
2. 한 줄을 붙여 넣고 엔터:

```
cd ~/block7 && git pull && cd gcal-functions/src && npm install && cd .. && firebase deploy --only functions:gcal
```
- 성공 표시: `worship(asia-northeast3)` 와 `worshipPull(asia-northeast3)` 옆에 **Successful create operation** (gcal · monday 는 *update*)
- 도중에 "SCHEDULE_API_KEY … 접근 권한을 줄까요?" 같은 물음이 나오면 **Y**
- "Cloud Scheduler API 를 켤까요?" 가 나오면 **Y** (2시간마다 깨우는 장치)
- ⚠️ 배포 중에 **삭제(deletion)를 묻는 화면이 나오면 반드시 N**
- `block7` 폴더가 없다고 나오면: `git clone https://github.com/Underkut/block7.git && cd block7/gcal-functions/src && npm install && cd .. && firebase deploy --only functions:gcal`

## 2. 보안 규칙 붙이기

`docs/rotation/firestore-rules.md` 의 '지금 붙일 덩어리' 를 예전처럼 통째로 바꿔 붙이고 **게시**.
(바뀐 것은 맨 끝의 `match /ext/{id}` 세 줄 — 받은 일정을 HB 와 팀 교역자가 읽기만 하게)

## 3. 확인

1. `sweeter.my/rotation/` 을 HB 계정으로 엽니다 (앱이 서버에 이름 맞추기 명단을 한 번 적습니다).
2. 오른쪽 위 **…**(계정) → **예배팀 일정 지금 받기**
3. '예배팀 일정을 받았습니다 · 예배 ○개' 가 나오면 끝. 단추 아래에 받은 때가 보입니다.
4. 부산 방문이 있는 주에 그분이 분당 예배팀에도 들어 있으면 그 방문이 빨갛게, 방문 판에 '부산에 있는데 분당 ○○ 예배팀(파트)' 가 나옵니다.

## 이럴 때

| 나오는 말 | 할 일 |
|---|---|
| 서버에 닿지 못했습니다 | 1번(서버 올리기)을 아직 안 했습니다 |
| 열쇠가 맞지 않습니다 | 0번 명령으로 열쇠를 다시 넣고 1번을 다시 |
| 오늘 받을 수 있는 횟수를 넘었습니다 | 한국 시각 자정 뒤에 저절로 다시 받습니다 |
| 예배팀 쪽 서버가 잠시 꺼져 있습니다 | 예배팀 로테이션 관리자에게 여쭙니다 |
| 받은 자료 모양이 다릅니다 | 예배팀 쪽 명세가 바뀌었을 수 있습니다 — 개발 창에 알려 주세요 |
| 같은 이름이 둘이라 못 맞춘 분: ○○ | 사람 탭에서 그분 이름을 예배팀에 적힌 이름과 다르게 구분할 수 있게 다른 이름을 고치거나, 개발 창에 알려 주세요 |
| 방금 받았습니다 (10분 뒤) | '지금 받기' 는 10분에 한 번만 됩니다 |

- 받기에 실패해도 마지막으로 받은 일정은 그대로 남습니다.
- 지난 날짜의 일정은 다음 받기 때 저절로 사라집니다(오늘부터 다음 달 말일까지만 받습니다).
