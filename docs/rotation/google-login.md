# 교역자 로테이션 — 교역자 구글 로그인 켜기 (HB, 한 번만)

교역자분들은 **구글(지메일)로** 들어온다. HB 는 지금처럼 **이메일 · 비밀번호**로 들어온다.
⚠️ HB 계정으로는 '구글로 로그인' 을 누르지 않는다 — 같은 지메일이면 파이어베이스가 두 로그인을 합치며 비밀번호 로그인이 풀릴 수 있다(BLOCK7 로그인이 흔들림).

먼저 `docs/rotation/firestore-rules.md` 의 보안 규칙을 바꿔 붙였는지 확인한다(R6a). 그다음 아래 셋.

## 1. 파이어베이스에서 구글 로그인 켜기

1. https://console.firebase.google.com → **block7-8f24e**
2. 왼쪽 **빌드** → **Authentication** → 위쪽 **로그인 방법**(Sign-in method) 탭
3. **새 제공업체 추가** → **Google**
4. 오른쪽 위 **사용 설정** 스위치를 켠다
5. **프로젝트 지원 이메일** 에서 HB 지메일을 고른다 → **저장**
   (공개용 이름은 그대로 둬도 된다 — 구글 창에 앱 이름으로 보인다)

## 2. sweeter.my 를 허용 도메인에 (있으면 그대로)

1. 같은 **Authentication** 화면 → 위쪽 **설정**(Settings) 탭 → 왼쪽 **승인된 도메인**(Authorized domains)
2. 목록에 `sweeter.my` 가 있으면 끝. 없으면 **도메인 추가** → `sweeter.my` → **추가**

## 3. 구글 클라우드에 돌아올 주소 한 줄 더하기

앱이 아이폰 홈 화면에서도 로그인이 끊기지 않게 **sweeter.my 자기 주소로 구글 창을 다녀온다.** 그 주소를 구글에 알려 줘야 한다.

1. https://console.cloud.google.com → 위쪽 프로젝트 고르기에서 **block7-8f24e**
2. 왼쪽 메뉴 ☰ → **API 및 서비스** → **사용자 인증 정보**(Credentials)
3. **OAuth 2.0 클라이언트 ID** 목록에서 **Web client (auto created by Google Service)** 를 누른다
   (1번을 마치면 생긴다. 이름이 조금 달라도 'Web client' 로 시작하는 것)
4. **승인된 리디렉션 URI** → **URI 추가** → 아래를 그대로 붙여 넣는다
   ```
   https://sweeter.my/__/auth/handler
   ```
   이미 있는 `https://block7-8f24e.firebaseapp.com/__/auth/handler` 는 **그대로 둔다.**
5. 맨 아래 **저장**. 적용까지 몇 분 걸릴 수 있다.

## 4. 교역자 맞이하기

1. 로테이션 앱 **사람** 탭 → 교역자 한 분을 펼쳐 **계정 이메일** 에 그분 지메일을 넣는다 (넣는 순간 그분만 들어올 수 있게 된다 — 빼면 바로 못 들어온다)
2. 그분께: `sweeter.my/rotation/` 을 열면 첫 화면이 로그인 화면이다 → **구글로 로그인** → 그 지메일 고르기 (사람 탭에 이메일이 있으면 이름 내기 없이 바로 들어온다)
   - 계정 이메일을 아직 모르면: 메뉴 → 계정 → **초대 링크 복사** 로 링크를 보내면, 그분이 구글로 들어와 이름을 내고 HB 가 교역자들 탭 맨 위 '로그인 신청' 에서 **교역자** 를 골라 승인한다(그 순간 사람 탭 계정 이메일이 채워진다 — 1122-V S3)
3. 들어오면 **달력표 · 내 일정** 이 먼저 열린다. 교역자분이 할 수 있는 것:
   - 모두 **보기**
   - **자기 부산 방문**의 숙소 · 교통 적기(방문을 눌러 숙소 · 교통 줄 → '저장') · 숙소 예약 화면 사진
   - **자기 부재 · 가능 일정**(내 일정 위 '내 부재 · 가능 일정 적기', 또는 … 메뉴)
   - 나머지(자리 고르기 · 자동 배열 · 사람 · 목록 관리 · 가져오기)는 HB 만
4. 교역자가 적은 것은 HB 앱에 바로 들어오고 '○○ 님이 적음' 이 붙는다. HB 가 다시 고치면 HB 것이 이긴다(나중에 적은 쪽).

## 안 될 때

- 앱에 **'구글 로그인이 아직 준비되지 않았습니다'** → 1번(구글 켜기)이나 2번(도메인)을 확인
- 구글 창에 **redirect_uri_mismatch** → 3번 주소를 다시 확인(글자 하나라도 다르면 안 됨). 저장 뒤 몇 분 기다린다
- 들어왔는데 **빈 화면 · '팀 명단에서 내 이름을 찾지 못했습니다'** → 사람 탭 계정 이메일 철자 확인(대문자 없이)
- 들어왔는데 **'초대 링크가 필요합니다'** → 사람 탭 계정 이메일이 그 지메일과 다르다. 철자를 고치거나 초대 링크를 보내 승인한다
- 구글 창에 '확인되지 않은 앱' 이 뜨면 캡처해서 보여 준다(이메일 · 이름만 묻는 로그인이라 보통은 안 뜬다)
