# 교역자 로테이션 알림 — 서버 올리기 · 켜기 (1123-B B4, 2026-11-24)

그 주 부산 섬기는 분(예배 인도 · 음향 · 봉독 …)을 정해 둔 때에 폰 알림으로 받습니다.
HB 님과 팀 교역자 모두 **자기 알림을 따로** 만듭니다(메뉴 → 계정 → 내 알림).

- **보안 규칙은 고칠 것이 없습니다.** 알림 설정은 서버만 읽고 쓰는 칸(`rotapush/{uid}`)에 둡니다.
- **서버를 한 번 다시 올려야 합니다.** 용돈 · 공부 친구들 · BLOCK7 알림과 같은 묶음(`wallet`)이라 명령도 그때와 같습니다.
- BLOCK7 · Sweeter 알림과는 **따로** 돕니다(기기 등록도 따로). BLOCK7 알림 설정은 바뀌지 않습니다.

## 1. 서버 올리기 (구글 Cloud Shell)

1. https://console.cloud.google.com 접속 → 위쪽 프로젝트가 **block7-8f24e** 인지 확인
2. 오른쪽 위 **>_ (Cloud Shell 활성화)** 아이콘
3. 아래 두 줄을 한 줄씩 붙여 넣고 엔터:

```
cd block7 && git pull && cd wallet-functions/src && npm install && cd ..
firebase deploy --only functions:wallet
```

- `block7` 폴더가 없다고 나오면 첫 줄 대신 `git clone https://github.com/Underkut/block7.git && cd block7/wallet-functions/src && npm install && cd ..`
- 성공 표시: `rotapush(asia-northeast3)` 가 **Successful create operation**, `studyTick(asia-northeast3)` 가 **Successful update operation**
  (같은 묶음의 다른 함수들은 **Successful update operation** — 정상입니다)
- ⚠️ 배포 중에 **삭제(deletion)를 묻는 화면이 나오면 반드시 N**

## 2. 폰에서 켜기 (기기마다 한 번)

1. 아이폰 홈 화면의 **로테이션 앱**을 엽니다 (사파리 창이 아니라 홈 화면 앱이어야 알림을 받습니다)
2. 오른쪽 위 **⋯ (메뉴)** → 위쪽 **계정** 탭 → **내 알림**
3. 맨 위 '이 기기' 줄의 **켜기** → 알림 허용 물음에 **허용**
4. 아래 목록에 **'주일 섬김'** 이 하나 생겨 있습니다(HB 님 결정 그대로 — 2부 · 예배 인도 · 음향 · 봉독 · 줄마다 · **토요일 저녁 8시**)
5. '주일 섬김' 을 누르면 고치는 판 → 맨 아래 **시험** → 몇 초 안에 '[시험] …' 알림이 오면 끝

패드 · 다른 폰에서도 받으려면 그 기기에서 2 ~ 3번을 한 번 더 합니다(만든 알림은 계정에 하나라 다시 만들 필요 없음).

## 3. 고치는 법 (내 알림 판)

- **어느 예배**: 금요 · 1부 · 2부 · 3부 · LL — 금요는 금요일 기준, 주일 예배는 주일 기준으로 한 통에 모입니다
- **모양**: 줄마다(기본) · 한 줄로 · 카톡 글 프리셋(예배 순서 판의 카톡 글을 그대로 — {본문} 줄은 빠짐)
- **무엇을 알고 싶나요**: 교역자 · 예배 인도 · 싱어 · 건반 · 음향 · 봉독 · 안내 · 헌금 · 광고
- **언제 · 어느 주**: 이틀 전 · 전날 · 당일 + 시각(30분 간격) + 모든 주 / 내 부산 주만 — **+ 때 더하기** 로 여러 개(예: 전날 저녁 8시 + 당일 아침 7시)
- **누르면 열릴 곳**: 예배 순서 · 예배별 / 사람별 / 카톡 글 / 내 일정
- 아래 **잠금 화면 미리보기**가 바로 바뀝니다. 막대는 제목 20자 · 본문 80자 기준(넘으면 잠금 화면에서 '…' 로 잘리고 길게 누르면 다 보임)
- 알림 옆 스위치로 잠깐 끌 수 있고, 판 아래 **지우기** 로 지웁니다. 알림은 6개까지.

## 4. 교역자께 안내할 말 (카톡에 붙여 넣기)

> 로테이션 앱에 알림이 생겼습니다. 홈 화면 앱 → 오른쪽 위 ⋯ → 계정 → 내 알림 → '이 기기' 켜기 → 허용.
> 처음엔 '주일 섬김'(토요일 저녁 8시, 2부 예배 인도 · 음향 · 봉독)이 있고, 눌러서 원하시는 대로 바꾸시면 됩니다.

## 문제가 생기면

- '알림 서버가 아직 올라가지 않았습니다' → 1번을 다시 (`rotapush` 가 **create** 로 올라갔는지)
- '이 로테이션의 팀 명단에 없습니다' → 사람 탭에서 그분의 **계정 이메일**이 로그인한 지메일과 같은지
- '이 브라우저는 알림을 받을 수 없습니다' → 아이폰 · 아이패드는 **홈 화면에 추가한 앱**에서 켜야 합니다
- 그 시각에 **로테이션 앱을 화면에 띄워 두고 있으면** 알림이 뜨지 않을 수 있습니다(파이어베이스 알림 도구가 열린 화면에 넘기고 배너를 안 띄움 — 심방 노트와 같음). 앱을 닫아 두면 옵니다.
- 알림이 안 옴 → 그 날 시트 표에 고른 정보가 없으면 보내지 않습니다(예: 2부만 골랐는데 그 주 2부가 분당 중계가 아닌데 이름이 비어 있음). 판의 미리보기가 '아직 없습니다' 면 그 때문입니다.

## 어떻게 도는가 (클로드용)

- 코드: `wallet-functions/src/rotapush.js`(파이어베이스 연결) · `rotapush-core.js`(서버만의 판단) · `rotation-core.gen.js`(**만들어진 파일** — 앱 `rotation/index.html` 의 `<script id="rotation-core">` 를 `tools/make-rotapush-core.sh` 가 떼어 만든다. 알림 글 · 보낼 때 · 설정 다듬기 `rp…` 는 앱과 한 벌. `check.sh` 가 낡았는지 본다)
- 저장 `rotapush/{uid}` = `{ team, email, ok, on, tokens:{등록 번호:{at, ua}}, alerts, at, last, fired, sent, err }` — 보안 규칙에 없다(서버만). 책 · `ui` · `staff` 칸 · `users/{uid}` 에는 쓰지 않는다.
- 1분 틱은 `studyTick` 에 얹었다(`rotaDue`). `at <= 지금` 인 사람만 묻고(잡기 트랜잭션 · 10분 넘게 늦은 것은 버림), **보낼 때만** 그 주 표 둘(`rota/{HB}/gs/bteam` · `gs/bserve`)을 읽는다. 책은 '내 부산 주만' · 교역자 · 카톡 글일 때만 한 번, 카톡 글 프리셋은 그 모양일 때만.
- 팀 확인: 주인은 uid 가 같을 때, 교역자는 `rota/{HB}` 의 `team` 칸만 읽어(fieldMask) 확인된 이메일이 들었을 때 — 보안 규칙 `inTeam` 과 같은 판단. 팀에서 빠지면 다음 때에 꺼진다.
- 함수 `rotapush`(HTTP, 로그인 토큰): `/status` · `/on` · `/off` · `/set` · `/test`. 앱 워커는 `/rotation/sw.js`(범위 `/rotation/`), 누르면 `?rp=svc|ppl|kt|mine&d=예배 날` → 앱 `rpBack`.
- 시험: `tests/test_rotapush.js`(check.sh) · `tests/rules/rotapush.e2e.mjs`(에뮬레이터에 실제 서버 파일을 붙여 — 로그인 · FCM 만 가짜).
