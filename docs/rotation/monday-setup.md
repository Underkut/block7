# 교역자 로테이션 — Monday 주일 광고 설정 (HB, 한 번만)

부산 방문 판과 '내 일정' 의 **주일 광고** 가 Monday 의 두 보드를 읽어 보여 줍니다 (R12 C).

| 보드 | 읽는 것 |
|---|---|
| **주일 영상 소식** | 방영일이 그 주일인 영상의 제목 · 유튜브 주소. 업데이트 · 댓글 중 '부산' 이 든 글 (화면에만) |
| **TLCB 주보** | 그 주일 그룹(`26-1122` 모양)에서 '구두 광고' 열에 번호가 매겨진 아이템의 **제목만**, 번호 순 |

- **읽기만** 합니다. Monday 에 글을 쓰거나 고치는 요청은 서버 코드에 아예 없습니다 (`tests/test_monday.js` 가 지킵니다).
- 분당 주보 · 글 내용 · '글' 열은 읽지 않습니다.
- Monday 열쇠(개인 API 토큰)는 **서버에만** 맡깁니다(`mondayKeys/{HB uid}`, 보안 규칙에 없는 칸이라 서버만 엽니다). 폰 · 교역자에게는 가지 않습니다.
- 교역자는 HB 열쇠로 서버가 읽은 **결과만** 받습니다. 사람 탭 '계정 이메일' 에 든 교역자만 받을 수 있습니다.
- 읽은 광고는 어디에도 저장하지 않습니다. 각 폰에 주일별 마지막 결과만 남겨, 다시 열 때 바로 보이게 합니다.

## 1. 서버 다시 올리기 (구글 Cloud Shell)

1. https://console.cloud.google.com → 위쪽 프로젝트가 **block7-8f24e** 인지 확인 → 오른쪽 위 **>_ (Cloud Shell 활성화)**
2. 한 줄을 붙여 넣고 엔터:

```
cd ~/block7 && git pull && cd gcal-functions && firebase deploy --only functions:gcal
```
- 성공 표시: `gcal(asia-northeast3)` 와 **`monday(asia-northeast3)`** 옆에 **Successful … operation** (monday 는 처음이라 *create* 로 나옵니다)
- ⚠️ 배포 중에 **삭제(deletion)를 묻는 화면이 나오면 반드시 N**
- `block7` 폴더가 없다고 나오면: `git clone https://github.com/Underkut/block7.git && cd block7/gcal-functions/src && npm install && cd .. && firebase deploy --only functions:gcal`

## 2. 앱에서 열쇠 넣기 (HB 계정으로)

1. Monday 에서 열쇠 복사: 오른쪽 위 **내 사진** → **개발자** → 개발자 센터 왼쪽 **API 토큰** → 개인 토큰 옆 **복사**
   - ⚠️ **'다시 생성(Regenerate)' 은 누르지 마세요.** 다시 만들면 예전 열쇠가 죽어서 메타 뮤즈 · 피클 연결도 함께 끊깁니다. **복사**만 합니다.
2. `sweeter.my/rotation/` → **부산** 탭 → 다가오는 방문 하나를 누름 → 맨 아래 **'… 주일 광고'** 줄
3. '처음 한 번 Monday 열쇠를 넣습니다' 칸에 붙여 넣고 **넣기**
   - 서버가 Monday 에 열쇠가 맞는지 물어본 뒤에만 맡깁니다. 맞지 않으면 '열쇠가 맞지 않습니다' 가 나옵니다.
4. 곧바로 그 주일의 광고가 나옵니다. **카톡용 복사** → 카톡에 붙여 넣기.

## 쓰는 법

- **부산 방문 판** 맨 아래 '주일 광고', 또는 교역자 '내 일정' 의 부산 카드 맨 아래 '주일 광고'.
- 카톡 글 양식(HB 11/16):
  ```
  11/15(주일) 부산 주일예배 광고

  1부: (그 주일 부산 방문의 교역자)
  2부: (같음)

  0: (영상) 영상 소식 제목
  분당 있음 / 부산 있음 (1부 중계, 2부 파일)

  1. 첫 구두광고 제목
  2. …
  > 모두 영상내 비포함
  >> 구두광고 및 슬라이드 필요
  ```
  - 둘째 줄(부산 상영)은 광고 판의 **같은 영상 / 다른 버전 / 부산 없음** 단추로 고릅니다 (처음 값 '같은 영상', 그 폰에만 기억). 영상이 없는 주는 '분당 없음 / 부산 없음'.
  - 마지막 두 줄은 영상 소식의 **리포터**가 배정됐으면 '모두 영상내 포함 / 구두광고 슬라이드 필요없음', 아니면 '모두 영상내 비포함 / 구두광고 및 슬라이드 필요'.
- 화면에만 있는 것: 유튜브 주소 · 부산 주보의 '영상 사용' · '확인 필요' 로 표시된 광고 · **부산 이야기**(영상 아이템의 업데이트 · 댓글 중 '부산' 이 든 글 — 분당만 · 다른 버전 같은 이야기가 여기 적힙니다).
- 부산 주보에 그 주일 그룹이 아직 없으면 '아직 그룹이 없습니다' 로 나옵니다. 담당자가 `Duplicate of …` 그룹 이름을 그 주일 날짜(`26-1122`)로 바꾸면 보입니다.

## 이럴 때

| 나오는 말 | 할 일 |
|---|---|
| 서버에 닿지 못했습니다 | 1번(서버 올리기)을 아직 안 했습니다 |
| Monday 열쇠가 아직 없습니다 (교역자 화면) | HB 가 2번을 합니다 |
| 열쇠가 맞지 않습니다 | Monday 에서 열쇠를 다시 **복사**해 넣습니다 (토큰을 새로 만들었을 때) |
| 리포터 배정을 읽지 못했습니다 | 서버가 옛것입니다 — 1번(서버 올리기)을 다시 합니다 |
| Monday 보드 모양이 바뀌었습니다 / 보드를 찾지 못했습니다 | 담당자가 보드 · 열 이름을 바꾸었거나 새 보드를 만들었습니다. 개발 창에 알려 주세요 — 보드 번호는 `gcal-functions/src/monday-core.js` 의 `BOARDS` 에 있습니다 |

- 연결을 거두려면: 광고 판 맨 아래 **Monday 연결 끊기** (서버에 맡긴 열쇠를 지웁니다. 교역자도 광고를 못 보게 됩니다).
