# 시리로 할일 넣기 — 설정 (HB, 한 번만) · v. 26-1026-3

"시리야, 블럭세븐 할일" → 시리가 "무엇을 넣을까요?" → **"내일 오전 우유 사기"** → 시리가 "블럭세븐에 보냈어요" →
BLOCK7 이 열려 있으면 곧바로, 아니면 다음에 열 때 **내일 · 오전** 칸에 '우유 사기' 가 들어가요.

## 1. 서버 올리기

알림 서버(`docs/push/setup.md`)와 **같은 묶음**이라 그 문서 **2번 명령 그대로** 올리면 함께 올라가요.
⚠️ 아직 알림 서버를 안 올렸다면 그 문서 **1번(옛 말씀 예약 일시중지)부터** 하세요 — 건너뛰면 말씀 알림이 두 번 와요.

성공 표시: `b7siri(asia-northeast3)` 가 **Successful create operation**

## 2. 주소 만들기 (아이폰 홈 화면 BLOCK7)

1. 오른쪽 위 톱니 → **계정** 탭 → **시리로 할일 넣기**
2. **주소 만들기** → "시리 주소를 만들었어요"
3. **주소 복사**

"주소를 만들지 못했어요" 가 나오면 1번(서버 올리기)이 아직이거나 인터넷이 끊긴 거예요.

## 3. 단축어 만들기 (아이폰 '단축어' 앱)

1. 오른쪽 위 **+**
2. **동작 추가** → 검색에 `입력` → **입력 요청** → 질문 칸을 눌러 `무엇을 넣을까요?`
3. 검색에 `URL` → **URL 콘텐츠 가져오기** → 파란 'URL' 칸을 눌러 **붙여넣기** (2번에서 복사한 주소)
4. 그 동작의 **›**(더 보기)를 눌러 펼치기
   - 방법: **POST**
   - 본문 요청: **JSON**
   - **새로운 필드 추가** → **텍스트** → 키 칸에 `text` → 값 칸을 누르고 위 변수 줄에서 **제공된 입력**
5. 검색에 `결과` → **결과 보기** (시리가 대답을 읽어 줘요)
6. 검색에 `메뉴` → **메뉴에서 선택** → 프롬프트 칸에 `확인하기` → 항목 두 개를 `보러 가기` · `취소` 로
7. `보러 가기` 아래에 검색 `URL` → **URL 열기** → 주소 칸에 `https://block7.my/` (`취소` 아래는 비워 둠)
8. 맨 위 이름을 `블럭세븐 할일` 로 → **완료**

시리가 이름을 잘 못 알아들으면 `할일 넣기` 처럼 쉬운 이름으로 바꿔도 돼요 (바꾼 이름으로 부르면 돼요).

## 3-2. 위젯용 단축어 (눌러서 날 → 구간 → 할일) — v. 26-1026-3

말하지 않고 **눌러서** 고르는 단축어. 홈 화면에 올려 위젯처럼 쓴다. 서버는 그대로 — 고른 것을 한 줄로 이어 같은 주소로 보낼 뿐이다.

1. 위 단축어를 **복제**하거나 새로 만든다
2. **목록에서 선택** `언제요?` → 항목 위에서부터 `오늘` `내일` `모레` `글피`
3. **목록에서 선택** `어느 구간이요?` → `지금 구간` + 내 구간 이름들 (첫 항목이 `지금 구간`)
4. **입력 요청** `무엇을 넣을까요?`
5. **텍스트** → 칸에 `선택한 항목(1번)`, 띄어쓰기, `선택한 항목(2번)`, 띄어쓰기, `입력` 변수를 이어 붙임
6. **URL 콘텐츠 가져오기** → 위와 같은 주소 · POST · JSON · 키 `text`, 값은 5번의 **텍스트**
7. **결과 보기** → 이름 `블럭세븐 할일 넣기` → 공유 버튼 → **홈 화면에 추가**

- `지금 구간` 은 구간을 안 고른 것과 같다: 오늘이면 지금 구간, 다른 날이면 펼친 첫 구간.
- 구간 이름을 바꿨으면 2번의 항목도 같은 이름으로 (안 맞으면 들은 말 그대로 내용에 남는다 — 잃지는 않는다).
- 앱 쪽 풀이는 `_siriParse` 가 `지금 구간` 을 알아본다 (`tests/test_siri.js` ⑩). 갱신 전 앱은 '지금 구간' 이 내용에 붙을 뿐 잃지는 않는다.

## 4. 말하는 법

**날 → 구간 → 할일** 차례로 말해요. 앞의 둘은 빼도 돼요.

| 말 | 들어가는 곳 |
|---|---|
| 내일 오전 우유 사기 | 내일 · 오전 · '우유 사기' |
| 모레 저녁 심방 | 모레 · 저녁 |
| 10월 30일 밤 기도회 | 10월 30일 · 밤 (지난 날짜면 내년) |
| 30일 오후 보고서 | 이번 달 30일 (지났으면 다음 달) |
| 점심때 약 먹기 | 오늘 · 점심 |
| 우유 사기 | 오늘 · **지금 구간** |
| 내일 우유 사기 | 내일 · **펼친 첫 구간** |

- 날: 오늘 · 내일 · 모레 · 내일모레 · 글피 · N월 N일 · N일 (뒤에 '은 · 에 · 날 · 까지' 가 붙어도 돼요)
- 구간: **내가 정한 구간 이름**. 이름을 바꿨어도 '아침 · 오전 · 점심 · 낮 · 오후 · 저녁 · 밤 · 새벽' 은 그 시각의 구간으로 가요.
- '새벽기도 가기' 처럼 붙여 말한 것은 쪼개지 않아요 (구간 없이 내용 그대로).
- 시리가 잘못 알아들어도 할일은 잃지 않아요 — 못 알아들은 부분은 내용에 그대로 남아요.

## 문제가 생기면

- 시리가 "주소가 맞지 않아요" → 다른 기기에서 **새로 만들기**를 눌렀거나 주소가 잘렸어요. 2번부터 다시 (단축어의 URL 칸만 바꾸면 돼요).
- 시리가 "쪽지가 너무 많이 쌓였어요" → BLOCK7 을 한 번 열면 쌓인 것을 다 넣고 비워요 (50개까지 기다려요).
- 주소는 열쇠예요. 남에게 보내지 마세요. 새어 나갔으면 **새로 만들기** — 옛 주소는 그 자리에서 멈춰요.

## 어떻게 도는가 (클로드용)

- 서버 `wallet-functions/src/b7siri.js` · 규칙 `b7siri-core.js` (`tests/test_b7siri.js`) — 열쇠 해시 `b7siri/{sha256}` = `{uid, at}` (보안 규칙에 없음, 서버만)
- 열쇠는 앱마다 하나 (2026-10-30) — 기도노트 '시리로 기도 넣기'(`/pray`, `docs/pray/siri-setup.md`)는 `app:'pray'`. BLOCK7 열쇠(`app` 없음)를 새로 만들어도 기도노트 주소는 그대로이고, 서로의 주소로는 못 보낸다
- 받으면 쪽지함 `pray/{uid}/c/b7inbox` 에 `{id, from:'siri', say, at, date, sec:'', text}` — 기도노트 '할일로 보내기' 와 같은 함
- 앱이 꺼낼 때 `_siriParse(say, at, SECS, ST.vis, dayStartHour)` 로 푼다 (`tests/test_siri.js`). 갱신 전 앱은 `date`(그날) · 첫 구간 · `text`(들은 말 그대로)로 넣는다
- 끝까지 시험: `tests/e2e/b7_siri.js` (에뮬레이터 + 진짜 서버 코드 + 기기 셋)
