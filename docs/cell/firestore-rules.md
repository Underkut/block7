# 셀 한눈에 — 전화번호 칸 보안 규칙 (HB, 한 번만)

셀 한눈에의 **전화번호**는 HB 파이어베이스(block7-8f24e)의 `cellbook/{uid}` 칸에만 저장한다.
BLOCK7 · Sweeter · 기도노트 · 용돈 친구들의 규칙은 건드리지 않고 **한 덩어리를 덧붙이기만** 한다.
이걸 붙이기 전에는 로그인은 되지만 명단 화면에 **"서버 권한이 아직 없습니다"** 가 뜬다.

## 보안 규칙 붙여 넣기

1. https://console.firebase.google.com → **block7-8f24e** → 왼쪽 **빌드** → **Firestore Database** → 위쪽 **규칙** 탭
2. 맨 위 `match /databases/{database}/documents {` 줄을 찾는다. 그 **바로 다음 줄**에 아래 덩어리를 붙여 넣는다.
   (기도노트 덩어리 `// ── 기도노트(pray) — 여기서부터 ──` 바로 위에 넣으면 된다)
3. 오른쪽 위 **게시**. 빨간 오류가 나오면 게시하지 말고 캡처해서 보여 준다.

```
    // ── 셀 한눈에(cellbook) — 여기서부터 ──
    match /cellbook/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
    // ── 셀 한눈에 — 여기까지 ──
```

로그인 방법(이메일/비밀번호)은 BLOCK7 이 이미 쓰고 있어서 따로 켤 것이 없다.

## 확인

1. 셀 한눈에 → 오른쪽 위 … → **명단 · 전화번호** → BLOCK7 과 같은 이메일 · 비밀번호로 로그인
2. 아무 셀원 번호를 넣고 칸을 벗어나면 칸 테두리가 잠깐 초록으로 빛난다 → 저장된 것
3. 다른 기기(아이패드 · PC)에서 같은 계정으로 로그인하면 같은 번호가 보인다

## 클라우드 모양 (참고)

- `cellbook/{uid}` — `phones`: { 셀원 id(셀 케어 cell_members.id) → { n: 이름, c: 셀 이름, p: 번호, at } } · `at` · `v`(앱 버전)
- 연락처 파일(.vcf) 내용은 어디에도 저장하지 않는다. 고른 번호만 남긴다.
- `users/{uid}`(BLOCK7 · Sweeter 상태 문서)는 건드리지 않는다.
