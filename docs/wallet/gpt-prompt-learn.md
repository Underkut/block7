# GPT 에게 줄 프롬프트 — 용돈 친구들 '배우고 퀴즈 풀기' 콘텐츠

> HB 가 GPT 에 그대로 붙여 넣는다. GPT 가 만든 JSON 을 클로드 코드에 주면 앱에 넣는다.
> 형식(스키마)을 바꾸려면 앱 쪽 불러오기 코드도 같이 바꿔야 하니, 여기서 먼저 고친다.

---

너는 초등학생을 위한 **기독교 가정 재정 교육 콘텐츠 작가**야. 아래 앱에 넣을 '배우고 퀴즈 풀기' 콘텐츠를 만들어 줘.

## 앱 소개 — "용돈 친구들"
- 초등학교 5학년 여자아이가 쓰는 한국어 용돈 기입장 앱(휴대폰). 부모는 기독교 가정.
- 아이가 하는 일: 받은 돈·쓴 돈 기록, 자산(현금·체크카드·통장) 관리, **계획 칸**(간식·문구·저금·헌금 등)에 돈 나눠 담기, **갖고 싶은 것 모으기**(목표 금액까지 저축), 하루 마무리에 "오늘 쓴 돈·받은 돈을 다 기록했나요?"에 **정직하게** 답하면 별을 받고 레벨이 오름.
- 레벨 칭호(1→10): 겨자씨 · 새싹 청지기 · 알뜰 탐험가 · 계획 꿈나무 · 슬기 청지기 · 부지런한 개미 · 나눔 대장 · 감사 마스터 · 믿음직 일꾼 · 용돈 박사.
- 앱의 말투: 귀여운 캐릭터(꿀꿀이 돼지 등)가 말하는 **다정한 존댓말·반말 섞인 아이 눈높이**. 혼내거나 겁주지 않는다. "돈을 많이 쓸수록 보상"이 되는 내용은 절대 없다.
- 이번에 추가할 것: 짧게 **배우고(카드 2~4장) → 퀴즈(3~5문제)** 를 풀면 별·아이템을 받는 단원들. 레벨이 오르면 다음 단원이 열린다.

## 다룰 내용 (골고루, 쉬운 것부터)
1. 기초: 돈은 무엇인가, 필요(need)와 원함(want), 기록의 힘, 계획(예산) 세우기
2. 저축: 목표 저축, 기다리는 힘(만족 지연), 통장·이자 기초, 비상금
3. 나눔과 헌금: 감사, 십일조·헌금의 의미(강요 아닌 기쁨), 이웃 돕기
4. 현명한 소비: 광고와 유혹, 비교하기, 충동구매·"한 박자 쉬기", 친구 따라 사기
5. 청지기의 자세: 모든 것이 하나님의 것이고 우리는 맡은 사람, 정직, 성실, 만족과 감사(욕심 경계)
6. 용어: 수입·지출·잔액·예산·저축·이자·신용·빚·체크카드와 신용카드 차이 등 (초5가 이해할 말로)
7. 고학년 심화(레벨 7~10): 빚과 이자의 무서움, 복리, 계획적인 큰 목표, 돈과 행복의 관계

## 성경 인용 규칙 (중요) — HB 수정 2026-10-10
- 구절마다 **개역개정**과 **쉬운성경** 두 본문을 함께 넣는다. 아이가 본문 화면에서 둘 중 골라 본다.
  (한두 구절 인용이라 저작권 문제가 없다는 HB 판단 — 성경 전체를 싣는 것이 아니다)
- 본문을 정확히 모르면 그 칸은 비워 둬라. 지어내거나 바꿔 쓰지 말 것.
- 예: 잠언 6:6(개미), 잠언 21:20, 누가복음 16:10(작은 것에 충성), 마태복음 25:14–30(달란트), 말라기 3:10, 고린도후서 9:7(즐겨 내는 자), 디모데전서 6:10, 빌립보서 4:11–12, 히브리서 13:5.

## 분량
- **단원 30개** (레벨 1~10 에 각 3개씩).
- 단원마다: 배우기 카드 2~4장(카드당 120자 이내), 퀴즈 3~5문제, 용어 0~3개.
- 퀴즈 종류 섞기: `ox`(O/X), `choice`(사지선다), `situation`(상황 판단: "민지는 1만원이 있는데…").
- 오답에도 **틀려도 괜찮아** 톤의 해설(`explain`, 80자 이내).

## 출력 형식 — 아래 JSON **한 덩어리만** 출력해 (설명 글 없이)
```json
{
  "version": 1,
  "units": [
    {
      "id": "u01",
      "level": 1,
      "theme": "기초",
      "title": "필요한 것과 갖고 싶은 것",
      "icon": "pig",
      "cards": [
        {"title": "꼭 필요한 것", "text": "…", "verse": {"ref": "잠언 21:20", "gae": "개역개정 본문", "easy": "쉬운성경 본문"}}
      ],
      "quiz": [
        {"id": "u01q1", "type": "ox", "q": "…", "answer": true, "explain": "…"},
        {"id": "u01q2", "type": "choice", "q": "…", "choices": ["…","…","…","…"], "answer": 2, "explain": "…"},
        {"id": "u01q3", "type": "situation", "q": "…", "choices": ["…","…","…"], "answer": 0, "explain": "…"}
      ],
      "glossary": [{"term": "지출", "easy": "돈을 쓰는 것", "example": "떡볶이를 사 먹은 3,000원"}],
      "reward": {"stars": 3, "item": {"id": "it_u01", "name": "…", "desc": "…"}}
    }
  ]
}
```
- `answer`: ox 는 true/false, choice·situation 은 **0부터 시작하는 번호**.
- `icon` 은 다음 중 하나: pig, bear, bunny, cat, dog, chick, hamster, owl, star, coin, gift, heart, church, cross, book, crown, gem, sun, flower, wallet.
- `reward.item` 은 아이가 모으는 수집품(예: "감사 일기장", "겨자씨 화분", "달란트 주머니")—이름 12자 이내, 설명 40자 이내. 돈이나 물건 구매를 부추기는 아이템은 금지.
- 같은 레벨 안에서 어려움은 첫 단원 < 셋째 단원.
- 모든 글은 한국어, 초등 5학년이 혼자 읽고 이해할 수 있게.

마지막으로, 출력 전에 스스로 확인해: JSON 문법이 맞는지, 단원 30개인지, `id` 가 겹치지 않는지, `answer` 번호가 `choices` 범위 안인지, 성경 본문이 개역개정·쉬운성경과 정확히 같은지(확실하지 않으면 그 칸 비움).
