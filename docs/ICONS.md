# 아이콘 자산 — 확정된 것

앱에 넣기로 **정해진** 아이콘의 원본 그림을 여기 모아둔다.
그리기만 해 보고 안 쓰기로 한 것은 넣지 않는다.

공통 규격 — `viewBox="0 0 24 24"`, `fill="none"`, `stroke="currentColor"`,
`stroke-linecap="round"`, `stroke-linejoin="round"`.
굵기는 쓰는 자리에 맡긴다 (앱바 단추는 `1.7`, 크게 볼 때는 `1.5`).

## 강대상 (교역자 출입구) — 2026-08-30 확정 · 안 이름 `D1`

Sweeter '명제집' 화면 **우상단 단추**에 쓴다. 누르면 교역자(설교 준비) 화면으로 간다.

성경책을 펼친 모양 + 기둥 + 받침. 다섯 안 중 HB 선택 —
"작게 보일 때도 명확하게 인지하기 좋다".
뱅커스 램프(서재 스탠드) 안도 그려 봤으나 18px 로 줄이면 형태가 뭉개져 쓰지 않는다.

```html
<svg viewBox="0 0 24 24" fill="none" stroke="currentColor"
     stroke-width="1.7" stroke-linecap="round" stroke-linejoin="round">
  <path d="M4 6.2c2.4-1.3 5.3-1.3 8 .6 2.7-1.9 5.6-1.9 8-.6v6.5c-2.4-1.3-5.3-1.3-8 .6-2.7-1.9-5.6-1.9-8-.6z"/>
  <path d="M12 6.8v6.5"/>
  <path d="M12 14.4v4"/>
  <path d="M7 19.4h10"/>
</svg>
```

네 줄이 각각 — 펼친 책 겉면 / 책의 가운데 접힌 선 / 기둥 / 바닥 받침.

⚠️ 책을 더 크게 하면 받침이 작아 보여 **가분수**가 된다.
처음 그린 것(책 폭 18.2)이 그랬고, 폭을 16 으로 줄이고 기둥을 늘려 균형을 잡은 것이 이 값이다.

## 태그 그림(말씀 주제 표시)은 여기가 아니다

말씀에 붙는 50 가지 손그림 표식은 `docs/TAG-ART.md` 에 따로 있다.
**둘을 섞어 쓰지 말 것.** 태그 그림은 *뜻*을 나타내고(비 = 은혜),
이 문서의 아이콘은 *기능*을 나타낸다(강대상 = 설교 준비로 가는 문).
같은 그림을 두 자리에 쓰면 사용자가 뜻을 잘못 읽는다.
