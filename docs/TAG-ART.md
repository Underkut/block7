# 태그 그림 그리기 규칙

말씀 전체화면 배경에 태그 그림을 띄우는 기능(`이미지 삽입`)을 위한 문서다.

**이 문서가 있는 이유.** 태그는 HB가 자유롭게 만들기 때문에 계속 늘어난다.
새 태그가 생길 때마다 "이 그림이 맞습니까?" 하고 물어볼 수는 없다.
그래서 **무엇을 그릴지 고르는 기준**과 **다 그린 뒤 스스로 검사하는 방법**을
여기에 못박아 둔다. 새 태그 그림을 그리는 도구는 이 문서만 보고 혼자 판단한다.

---

## 규칙 1 — 상징은 순위대로 고른다. 섞지 않는다

| 순위 | 무엇을 | 예 |
|---|---|---|
| 1 | **성경에 직접 나오는 표준 상징**이 있으면 무조건 그것 | 성령 = 비둘기 (마 3:16) · 말씀 = 등불 (시 119:105) · 구원 = 십자가 |
| 2 | 표준 상징이 없으면 그 단어의 **몸짓·행동** | 순종 = 무릎 꿇음 · 은혜 = 받는 손 · 감사 = 모은 손 |
| 3 | 몸짓도 없으면 그 단어가 **눈에 보이는 결과** | 소망 = 새싹 · 평안 = 잔잔한 물 |

**한 그림에 상징은 하나만.** 비둘기 + 빛줄기 + 구름을 함께 그리면
셋 다 흐려지고 아무것도 안 읽힌다. 1차 시안이 정확히 이래서 실패했다.

**고른 이유를 한 문장으로 못 쓰면 그 상징은 버린다.**
"비둘기 — 예수 세례 때 비둘기같이 내려오심"처럼 근거를 댈 수 있어야 한다.

---

## 규칙 2 — 그리고 나면 반드시 눈으로 본다 (제일 중요)

코드로만 쓰고 넘기지 말 것. 그린 사람은 자기가 뭘 그렸는지 알기 때문에
무조건 알아보인다. 처음 보는 사람 눈에는 전혀 다른 게 보인다.

```
node tools/icon-shot.js 작업.html 결과.png     # PNG 로 뽑아서 직접 본다
```
(playwright 를 못 찾으면 앞에 `NODE_PATH=$(npm root -g)` 를 붙인다)

**보는 방법**: 태그 이름을 가리고 **"이게 뭐로 보이나"를 먼저 판정**한다.
그 답이 태그와 다르면 그림이 틀린 것이다. 도안을 고치지 말고 **상징을 바꾼다.**

2026-08-25 에 이 검사로 걸러낸 것들 — 전부 코드만 봤을 때는 멀쩡해 보였다:

| 그리려던 것 | 실제로 보인 것 |
|---|---|
| 은혜 = 오목하게 모은 두 손 | 이빨 드러낸 **웃는 입** (손가락 선이 이빨이 됐다) |
| 순종 = 길 위의 발자국 | **밀 이삭** |
| 순종 = 양 | 구름 옆에 붙은 **소용돌이** |
| 은혜 = 구름에서 내리는 빛 | 그냥 **비구름(날씨)** |
| 성령 = 정면에서 본 비둘기 | **비행기·나방** (새는 정면에 실루엣이 없다) |
| 은혜 = 측면으로 편 손 | **초승달·뿔**, 엄지는 소용돌이 |
| 은혜 = 받쳐 든 두 손 | 또 **구름** |
| 순종 = 삼각형 옷자락 | **텐트·산** |
| 은혜 = 잔 + 바깥으로 휘는 넘침 곡선 | 손잡이가 달린 **트로피** |

## 규칙 3 — 세 가지 조건에서 확인한다

한 번 크게 봐서 괜찮은 건 아무 의미 없다. 실제로 쓰이는 조건에서 봐야 한다.

1. **크게** (220px) — 형태가 맞는지
2. **작게** (96px) — 실제 표시 크기. 가는 선과 잔 디테일이 뭉개져 사라진다
3. **어두운 배경 · 오패시티 30%** — 실제 사용 조건. 여기서 안 보이면 못 쓴다

---

## 규칙 4 — 그리는 요령 (실패에서 뽑은 것)

- **윤곽선은 사물의 실루엣을 따라간다.** 장식선을 긋지 않는다.
  선 하나하나가 "이 물건의 어느 모서리인지" 답할 수 있어야 한다.
- **짧은 평행선을 여러 개 나란히 긋지 말 것.** 이빨·빗살·이삭으로 보인다.
- **좌우 대칭 + 아래로 볼록**은 웃는 입이 된다. 비대칭으로 깨뜨린다.
- **눈 점 하나**가 생물이냐 아니냐를 가른다. 동물에는 반드시 찍는다.
- 부리·귀처럼 **작고 뾰족한 부분은 본체 윤곽에 넣지 말고 따로 그린다.**
  윤곽에 넣으면 부리가 몸통만큼 두꺼워져서 새가 아니라 원뿔이 된다.
- 사람은 **머리(원) + 몸통 곡선 + 팔다리**로 나눠 그린다. 자세가 곧 뜻이므로
  자세가 읽히는 게 형태보다 중요하다.
- **새·짐승은 반드시 옆모습.** 정면에서 그리면 알아볼 실루엣이 없어 비행기·나방이 된다.
  움직임(내려온다·달린다)은 **몸 전체를 기울여서** 낸다. 화살표나 빛줄기를 덧붙이지 않는다.
- **손은 그리지 않는 편이 낫다.** 정면 손바닥은 'STOP' 과 타 종교의 손 문양으로 먼저 읽히고,
  측면으로 돌리면 초승달·뿔이 된다. 손으로 표현하고 싶은 뜻은 **그릇·잔** 쪽으로 바꾼다.
- 그릇 옆에 **바깥으로 휘는 곡선**을 붙이면 손잡이가 되어 트로피로 보인다.
  넘침·채워짐은 **위에서 떨어지는 방울**로 낸다.
- 사람의 옷자락을 곧은 삼각형으로 그리면 텐트·산이 된다. **목과 어깨선을 반드시 드러낸다.**

## 규칙 5 — 진지한 그림체 (귀여워지지 않기)

단순하게만 그리면 자동으로 귀여워진다. 세 가지가 원인이다.

| 원인 | 기준 |
|---|---|
| 선이 굵다 | viewBox 200 기준 **2.4**. 4 는 만화가 된다 |
| 머리가 크다 | 사람 머리는 전체 높이의 **1/5 이하**. 1/3 이면 데포르메(귀여움)다 |
| 내부가 비었다 | 깃털·옷주름 같은 **내부선 2~3개**(굵기 1.3~1.9)가 밀도를 만든다 |

## 스타일 규격 — 두 벌을 같은 도안으로 만든다

도안(path)은 **하나만** 그린다. 스타일은 그 도안을 어떻게 그리느냐의 차이다.
그래야 나중에 도안을 고치면 두 스타일이 같이 고쳐진다.

**minimal** — 깔끔하고 상징적인 드로잉라인
```
fill="none" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round"
```
내부 디테일선은 `stroke-width="1.3"~"1.9"` 로 따로 준다.

**organic** — 아날로그·빈티지 펜슬 드로잉
같은 도안에 필터 두 개를 겹쳐 쓴다.
```html
<filter id="wb">  <!-- 손떨림: 저주파로 선을 굽힌다 -->
  <feTurbulence type="fractalNoise" baseFrequency="0.035" numOctaves="2" seed="3" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="3"/>
</filter>
<filter id="gr">  <!-- 연필 결: 고주파로 선을 거칠게 -->
  <feTurbulence type="fractalNoise" baseFrequency="0.8" numOctaves="2" seed="5" result="n"/>
  <feDisplacementMap in="SourceGraphic" in2="n" scale="1.6"/>
</filter>
```
```html
<g filter="url(#wb)"><g filter="url(#gr)" fill="none" stroke-width="2.2"
   stroke-linecap="round" stroke-linejoin="round"><use href="#도안"/></g></g>
```
`baseFrequency` 를 낮추면 흐물흐물해지고, 올리면 지저분해진다. 위 값이 기준선이다.
**선을 얇게 할수록 흔들림(scale)도 같이 줄여야 한다.** 안 그러면 선이 끊어져 보인다.

## 화면에 얹는 규칙

- viewBox 는 **`0 0 200 200`** 으로 통일. 그림은 대략 `30~170` 안에 담는다
- 크기는 화면 폭의 **40%**, 오패시티 **30%**
- 위치는 좌상·우상·좌하·우하 **네 모서리 중 랜덤**, 여백 5%
- 색은 글자색을 따라간다 (`stroke="currentColor"`) — 테마가 바뀌어도 같이 간다
- 말씀에 태그가 여럿이면 그중 **하나를 랜덤**으로 고른다
- **그림이 없는 태그면 아무것도 그리지 않는다.** 비슷한 걸 갖다 붙이지 말 것

---

## 코드에 넣는 형식

도안은 `<defs>` 안에 `<g id="ic-태그이름">` 로 한 번만 정의하고,
쓸 때는 `<use href="#ic-태그이름"/>` 로 부른다. 스타일 두 벌이 같은 도안을 공유한다.

태그 이름 → 도안 id 는 표 하나로 관리한다. 표에 없는 태그는 그림 없음으로 둔다.
