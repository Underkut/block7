말씀 관련 우클릭 메뉴 체크표

가로축은 메뉴를 여는 화면, 세로축은 메뉴 항목입니다. 왼쪽 ⋮⋮ 손잡이로 순서를 바꾸고 연필 버튼으로 이름을 고칠 수 있습니다.

GitHub에서 불러오는 중…

GitHub에 연결하면 수정값이 모든 기기에 공유됩니다.

GitHub의 Fine-grained token을 만들 때 이 저장소의 Contents: Read and write, Pull requests: Read and write 권한을 주세요. 토큰은 이 기기에만 보관하며 GitHub 이외에는 보내지 않습니다.

✓ 현재 운영 메뉴에 있는 항목은 미리 체크되어 있습니다.노란색은 처음 상태에서 바꾼 칸입니다.같은 항목에 아이콘이 둘이면 왼쪽 칸에서 하나를 고를 수 있습니다.표 안을 위아래·좌우로 스크롤할 수 있습니다.

‘이 목록에서 빼기’와 ‘저장 풀기’는 어디에 있나요?

지금 실제로 찾아갈 수 있는 화면에는 ‘저장 풀기’가 없습니다. 제가 앞서 ‘전체 저장 보기’에 있다고 설명한 것은 잘못이었습니다.

실제 경로는 좌상단 BLOCK7 로고를 길게 누르기(PC는 우클릭) → 저장 목록 → 목록 이름 선택 → 말씀 한 줄을 길게 누르기(PC는 우클릭)입니다. 여기에는 그 말씀을 현재 선택한 목록에서만 빼는 ‘이 목록에서 빼기’가 나옵니다.

‘저장 풀기’ 행은 여러 저장 목록에서 한꺼번에 빼는 기능을 새로 둘지 검토하기 위한 후보입니다. 현재 앱에서는 들어갈 수 있는 화면이 없으므로 미리 체크하지 않았습니다.

순서·문구 등 추가 의견

연결 뒤 체크·행 순서·가로선·추가 의견은 GitHub에 자동 저장되어 모든 기기와 개발 도구가 같은 값을 봅니다. ‘운영본 PR 만들기’를 누르면 저장된 변경안을 검토할 PR을 엽니다.
