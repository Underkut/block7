# 명제 대표 문구 글씨체 (직접 올린 것)

설교 명제 전체화면 위쪽 **대표 문구**에 쓰는 손글씨·명조체다.
HB 가 눈누(noonnu.cc)에서 받아 준 것을 웹에서 쓸 수 있게 **잘라 넣었다**.

고르는 자리: 말씀 설정 → 전체화면 탭 → **명제 타이틀** (파워 등급)

## 어떻게 만들었나

원본 TTF → 한글만 남기고 잘라 냄 → woff2 로 압축.
원본 1.5~14MB 가 184~987KB 가 됐다 (합계 3.2MB).

```
python3 -m fontTools.subset <원본>.ttf --flavor=woff2 --no-hinting \
  --desubroutinize --drop-tables+=DSIG \
  --unicodes=U+0020-007E,U+00A0,U+2018-201D,U+2026,U+3131-318E,U+AC00-D7A3
```

- 대부분은 **한글 11,172자 전부**를 남겼다.
- `daegwang` · `griun` 은 그러면 너무 커져서 **실용 2,780자**만 남겼다
  (KS X 1001 2,350자보다 넉넉하다. 아주 드문 글자는 본문 글씨체로 나온다).

⚠️ 크기 배율(`--pt-k`)은 눈대중이 아니라 **글자의 잉크 높이를 재서** 정했다.
   나눔붓·송명·고운바탕이 이루는 가운뎃값(0.893)에 맞췄다.

## 어떻게 쓰이나

- `index.html` 의 `@font-face` 가 `fonts/*.woff2` 를 가리킨다.
- **미리 받지 않는다.** 그 글씨체가 뽑힌 명제를 열 때 그때 받는다
  (여덟 벌을 앱 켤 때 다 받으면 3.2MB 다).
- `font-display:block` — 오는 동안 글자를 잠깐 감춘다. 딴 글씨체로 먼저
  그렸다가 바뀌면 깜빡인다 (HB 26-0831 신고).
- 한 번 받으면 기기에 남는다. 다음부터 다시 받지 않는다.

⚠️⚠️ **라이선스 확인은 끝난 것이 아니다.**
글씨체 파일 안에 라이선스 글이 들어 있는 것은 **LXGW(SIL OFL)와 그리운** 둘뿐이다.
나머지 여섯은 파일에 표기가 없어 **눈누 각 폰트 페이지의 '웹폰트' 칸**이
허용인지가 유일한 근거다. 운영 배포 전에 반드시 다시 확인할 것.
허용이 아닌 것이 있으면 그 줄을 표에서 빼고 파일을 지운다.

## 글씨체를 더할 때

고칠 곳은 **세 군데**다.
1. `fonts/` 에 잘라 낸 woff2 를 넣는다
2. `index.html` 의 `@font-face` 와 `.vf-ptitle.pf-<열쇠>` (배율 `--pt-k`)
3. `index.html` 의 `_PT_FACES` 표에 `{k, ko, full, fam, self:1}` 한 줄

나머지(설정창 단추·미리 받아 두기·무작위 배정)는 그 표에서 저절로 따라온다.
