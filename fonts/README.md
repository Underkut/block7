# 명제 대표 문구 글씨체 (직접 올린 것)

설교 명제 전체화면 위쪽 **대표 문구**에 쓰는 손글씨·명조체다.
HB 가 눈누(noonnu.cc)에서 받아 준 것을 웹에서 쓸 수 있게 **잘라 넣었다**.

고르는 자리: 말씀 설정 → 전체화면 탭 → **명제 타이틀** (파워 등급)

## 어떻게 만들었나

원본 TTF → 한글만 남기고 잘라 냄 → woff2 로 압축.
⚠️ **자르는 것은 라이선스에서 '수정'으로 본다.** OFL 은 허용하지만
   허용하지 않는 글씨체가 많다 — 아래 '더하기 전에' 를 반드시 읽을 것.

```
python3 -m fontTools.subset <원본>.ttf --flavor=woff2 --no-hinting \
  --desubroutinize --drop-tables+=DSIG \
  --unicodes=U+0020-007E,U+00A0,U+2018-201D,U+2026,U+3131-318E,U+AC00-D7A3
```

- 대부분은 **한글 11,172자 전부**를 남겼다.
- `daegwang` · `barun` · `uridal` 은 그러면 3MB 가 넘어 **실용 2,694자**만 남겼다
  (KS X 1001 2,350자 + 잦은 조합. 아주 드문 글자는 본문 글씨체로 나온다).

⚠️ 크기 배율(`--pt-k`)은 눈대중이 아니라 **글자의 잉크 높이를 재서** 정했다.
   나눔붓·송명·고운바탕이 이루는 가운뎃값(0.893)에 맞췄다.

## 어떻게 쓰이나

- `index.html` 의 `@font-face` 가 `fonts/*.woff2` 를 가리킨다.
- **미리 받지 않는다.** 그 글씨체가 뽑힌 명제를 열 때 그때 받는다
  (여덟 벌을 앱 켤 때 다 받으면 2.6MB 다).
- `font-display:block` — 오는 동안 글자를 잠깐 감춘다. 딴 글씨체로 먼저
  그렸다가 바뀌면 깜빡인다 (HB 26-0831 신고).
- 한 번 받으면 기기에 남는다. 다음부터 다시 받지 않는다.

## 글씨체를 새로 더하기 전에 — **라이선스를 먼저 확인한다**

확인할 것은 **셋**이다. 하나라도 안 되면 쓸 수 없다.

1. **상업적 이용**이 되는가
2. **웹폰트** — 우리 서버에 올려 방문자에게 전송해도 되는가
3. **서브셋** — 필요한 글자만 남기고 잘라도 되는가 (우리는 반드시 자른다)

⚠️ 한국 무료 글씨체는 **①만 되고 ②③은 막는 경우가 흔하다.**
   눈누 같은 정리 사이트의 요약표는 근거가 못 된다 — **제조사 원문**을 본다.
   글꼴 파일 안의 "All rights reserved" 는 허락이 아니라 저작권 선언일 뿐이다.
   (2026-09-02 에 스물두 벌을 이 까닭으로 지웠다. 같은 일을 되풀이하지 말 것)

## `prev/` — 설정창 단추용 초소형 글꼴 (합계 29KB)

⚠️⚠️ 이것이 없으면 **설정창을 여는 것만으로 스물일곱 벌 9.7MB를 다 받는다.**
`@font-face` 는 그 글씨체가 화면에 쓰이는 순간 받아지는데, 설정창 단추
스물일곱이 저마다 제 글씨체로 쓰여 있으니 전부 쓰이는 셈이다.

→ 단추에는 **제 이름표 글자만 담은 1KB짜리** 글꼴(`B7P …`)을 먼저 세운다.
   진짜 글꼴은 그 글씨체가 뽑힌 명제를 열 때 받는다.

```
python3 -m fontTools.subset fonts/<파일>.woff2 --flavor=woff2 --no-hinting \
  --desubroutinize --drop-tables+=DSIG --text=<이름표> \
  --output-file=fonts/prev/<열쇠>.woff2
```

⚠️ 이름표(`_PT_FACES` 의 `ko`)를 고치면 **이 글꼴도 다시 잘라야 한다.**
   안 자르면 새 글자가 빠져 단추에서 그 글자만 기본 글씨체로 나온다.
⚠️ 파일 이름은 진짜 글꼴과 달리 **열쇠(k)** 를 쓴다 (`chosunN.woff2`).

## 글씨체를 더할 때

고칠 곳은 **네 군데**다.
1. `fonts/` 에 잘라 낸 woff2 를 넣는다
2. `fonts/prev/` 에 **이름표 글자만** 잘라 낸 woff2 를 넣는다 (위 참고)
3. `index.html` 의 `@font-face` 두 줄(`B7 …` · `B7P …`)과
   `.vf-ptitle.pf-<열쇠>` (배율 `--pt-k`)
4. `index.html` 의 `_PT_FACES` 표에 `{k, g, ko, full, fam, self:1}` 한 줄
   — `g` 는 무리다 (`m` 명조 · `g` 고딕 · `h` 손글씨). **안 적으면 손글씨로 간다.**

나머지(설정창 단추·무리 나누기·무작위 배정)는 그 표에서 저절로 따라온다.

⚠️ 배율(`--pt-k`)은 잉크 높이를 재서 정하되, **명조는 거기에 ×1.275 를 곱한다.**
   명조는 본문 글씨체와 결이 가까워서 맞춘 크기로는 타이틀과 본문이 구분되지
   않는다 (HB 26-0902, 고운바탕에서 확인). 고딕·손글씨는 잰 값 그대로.
