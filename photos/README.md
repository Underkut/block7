# photos/ — 타일에 까는 사진

Sweeter 홈 타일의 **바탕 사진**이 여기 있습니다. (v26-0922-4, HB 선택 ①+②)

사진이 정해지는 차례는 둘입니다.

1. **시트에 적힌 사진** — 명제 DB(또는 성도 공유용) 시트에 `사진 링크` 열을 만들고
   `https://...` 주소를 적으면 **그 말씀에는 그 사진**이 뜹니다. 그 주의 사진을
   교역자가 직접 고르는 자리입니다. (구글 드라이브 '보기' 주소를 붙여도 앱이
   그림 주소로 바꿔 줍니다 — 드라이브 파일은 '링크가 있는 모든 사용자'로 공개해야 합니다)
2. **여기 있는 사진첩** — 시트에 아무것도 없으면 말씀의 **태그·상황**에 맞는 사진을
   이 폴더에서 고릅니다. 없으면 사진 없이 예전 모습 그대로입니다.

## 사진을 더하는 법

1. 파일을 이 폴더에 넣습니다. **이름은 영문 소문자와 붙임표만** (`still-water.jpg`).
2. `photos/manifest.json` 에 한 줄 더합니다.

```json
{ "f": "still-water.jpg", "for": ["평안", "쉼", "안식"], "by": "촬영자 이름 / 출처" }
```

   * `f`   — 파일 이름
   * `for` — 이 사진이 어울리는 **태그·상황** 말들 (여러 개)
   * `by`  — 어디서 왔는지 (저작권을 나중에 확인할 수 있게 **반드시** 적습니다)

## 지켜야 할 것

* **크기**: 가로 1200px 안팎, 한 장 **200KB 이하**로 줄여서 넣습니다.
  타일은 작게 쓰므로 그보다 크면 앱만 무거워집니다.
* **저작권**: 직접 찍은 사진, 또는 상업적 이용·재배포가 되는 것만 넣습니다.
  지금 들어 있는 86장은 **전부 Unsplash 무료**입니다 (2026-09-22 HB 확인).
  (글꼴과 같은 규칙입니다 — `fonts/README.md` 참고)
* **결**: 글자가 위에 얹히므로 **한쪽이 비어 있고 대비가 낮은** 사진이 좋습니다.
  사람 얼굴이 크게 나온 사진은 피합니다.
* 사진이 한 장도 없어도 앱은 그대로 돕니다 (사진 없이 예전 모습).
