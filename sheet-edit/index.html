시트 편집 문 설치

BLOCK7 · Sweeter 앱 안에서 구글 시트 칸을 고치려면 이 문(구글 앱스 스크립트)이 필요합니다. PC 크롬에서, 시트 주인 계정(denartist@gmail.com)으로 로그인한 채로 하세요. 5분쯤 걸립니다.

  1. 새 프로젝트 만들기
    아래 단추로 앱스 스크립트를 열고, 왼쪽 위 ＋ 새 프로젝트 (New project) 를 누릅니다.
    script.google.com 열기
  2. 이름 붙이기
    위쪽 제목 없는 프로젝트 를 누르고 BLOCK7 시트 편집 문 이라고 쓴 뒤 이름 바꾸기.
  3. 코드 붙여넣기
    편집기에 이미 있는 function myFunction() { } 을 모두 지웁니다 (편집기 안을 한 번 누르고 Ctrl + A → Delete). 그다음 아래 단추를 누르고 편집기에 Ctrl + V.
    코드를 불러오는 중…
  4. 저장
    Ctrl + S (또는 위쪽 디스크 모양 아이콘).
  5. 배포 시작
    오른쪽 위 파란 배포 (Deploy) → 새 배포 (New deployment).
  6. 웹 앱 고르기
    왼쪽 '유형 선택' 옆 톱니바퀴 → 웹 앱 (Web app).
  7. 두 칸 정하기
    • 다음 사용자 인증 정보로 실행 (Execute as) → 나 (denartist@gmail.com)
    • 액세스 권한이 있는 사용자 (Who has access) → 모든 사용자 (Anyone)
    설명 칸은 비워 둬도 됩니다. 배포 를 누릅니다.
    ⚠️ 'Google 계정이 있는 모든 사용자' 가 아니라 '모든 사용자' 입니다. 앞의 것을 고르면 앱이 문을 열지 못합니다. 누구나 문 앞까지는 올 수 있어도, HB 로그인 표가 없으면 아무것도 못 합니다 (아래 '무엇을 하나요').
  8. 허락하기 (처음 한 번)
    액세스 승인 (Authorize access) → 계정 고르기 → 'Google에서 확인하지 않은 앱' 이 나오면 왼쪽 아래 고급 (Advanced) → BLOCK7 시트 편집 문(으)로 이동(안전하지 않음) → 허용 (Allow). 항목을 고르는 화면이면 모두 선택 후 계속.
    '확인하지 않은 앱' 은 HB 가 직접 만든 스크립트라 구글 심사를 받지 않았다는 뜻입니다.
  9. 주소 복사
    '웹 앱' 아래 URL 옆 복사 (Copy) → 완료. https://script.google.com/macros/s/…/exec 모양입니다.
  10. 살아 있나 보기
    새 탭 주소창에 붙여 넣고 엔터 → 'BLOCK7 시트 편집 문 — 살아 있어요 ✓' 가 보이면 설치는 끝입니다.
  11. 앱에 붙이기
    BLOCK7 → 설정(톱니) → 계정 탭 맨 아래 시트 편집 문 칸에 붙여 넣고 연결 확인 → '연결됐어요 ✓' 가 뜨면 끝입니다. 한 기기에서만 하면 다른 기기와 Sweeter 에도 따라갑니다.
    ⚠️ 이 주소는 저장소(공개)나 단톡방 같은 곳에 올리지 마세요. HB 로그인 없이는 아무것도 못 하지만, 굳이 알릴 이유가 없습니다.

코드가 바뀌었을 때

앱이 '문이 옛 버전이에요' 라고 하면 — script.google.com → BLOCK7 시트 편집 문 → 코드를 모두 지우고 위 코드 복사 로 새로 붙여넣기 → 저장 → 배포 → 배포 관리 (Manage deployments) → 연필(수정) → 버전 새 버전 (New version) → 배포. 주소는 그대로라 앱에서 고칠 것이 없습니다.

⚠️ '새 배포' 를 또 만들면 주소가 바뀝니다. 바뀐 코드는 '배포 관리' 에서 새 버전으로 올리세요.

무엇을 하나요

  • 앱 안 편집 창이 시트 칸을 고칠 때 이 문을 거칩니다. HB 계정으로 돌기 때문에 HB 시트에 쓸 수 있습니다.
  • 허락하는 것 두 가지 — ① 구글 시트 보기·편집 (칸을 고치려고) ② 외부 서비스 연결 (부른 사람이 HB 인지 구글 로그인 확인 서버에 물으려고).
  • 부른 사람이 HB 로그인이 아니면 아무것도 하지 않습니다.
  • 하지 않는 것 — 행 만들기·지우기 · 머리글 줄 · '명제 ID' 같은 ID 열 · 수식 칸 · 한 번에 30칸 넘게.
  • 고치기 전 값이 그사이 시트에서 바뀌었으면 아무것도 고치지 않고 알려 줍니다.
